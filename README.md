# Production-Vision-Inspection
ROI 전처리, 이상 탐지, 운영 임계값 튜닝, FastAPI 서빙, 드리프트 모니터링, MFC 데모 클라이언트를 포함한 엔드투엔드 비전 검사 포트폴리오 프로젝트. End-to-end vision inspection portfolio project with ROI preprocessing, anomaly detection, operating-threshold tuning, FastAPI serving, drift monitoring, and an MFC demo client.
